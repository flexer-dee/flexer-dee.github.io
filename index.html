01Now

Embedded & IoT Engineer, Ubuntu Waterhub Africa

Jul 2026 – present · part-time · attachment May–Jun 2026

Ubuntu Waterhub runs prepaid, IoT-enabled water ATMs and smart meters for underserved communities across Kenya and East Africa. A kiosk that drops offline is a community without water, so the work is mostly about reliability under bad conditions: intermittent cellular coverage, solar power budgets, and hardware that has to survive in the field.

I debug and extend the C/C++ firmware on NB-IoT prepaid meters — sensor data processing, offline logging, and M-Pesa payment integration over cellular modules. I diagnose PCBs returned from the field down to root cause and feed the fix back into the hardware revision, run power consumption analysis to stretch battery life on off-grid, solar-charged sites, and watch data integrity and signal propagation across deployed kiosks so no usage or revenue data is lost between visits.

Why it matters: a kiosk that silently drops offline looks fine until the meter runs out of readings to bill against — this work is what keeps the difference between "still working" and "quietly losing revenue" visible before it becomes a field visit.

Models and forecasting

Hyper-Local Predictive Weather Platform

RGoogle Earth EngineFastAPIrpy2React

A forecasting tool scaled to a single microclimate. It pulls CHIRPS satellite rainfall rasters through Google Earth Engine, then applies quantile-mapping bias correction against ground-station telemetry to calibrate the satellite proxy to local truth.

A Support Vector Regression model predicts continuous rainfall; a Markov chain classifier resolves that into clear, rain or storm states. The serialised R models are loaded into a Python FastAPI server via rpy2 and served to a React dashboard.

Use case: general weather APIs forecast for a whole city or region — this recalibrates that against ground-station truth for one specific microclimate, which is what actually matters if you're deciding whether to irrigate a plot in Madaraka this afternoon.
github.com/flexer-dee/Hyperlocal_weather_forecaster

Real-Time Facial Recognition Attendance

PythonOpenCV DNNONNX (YuNet, SFace)

Attendance logging built to run on standard CPU hardware without TensorFlow or PyTorch. YuNet locates faces and returns five landmarks; SFace uses those to align and crop before producing a 128-dimension embedding, matched by cosine similarity against pre-computed embeddings at a 0.363 threshold.

Use case: real-time recognition for classrooms or offices without a GPU budget — a laptop or a low-cost single-board computer is enough, which matters anywhere buying dedicated inference hardware isn't realistic.

Multi-AZ AWS Infrastructure & Stampede-Resilient Caching

TerraformJenkinsAWS VPC / RDS / ElastiCacheRedisPython

A VPC across three availability zones, declared in Terraform, with strict subnet isolation between NAT gateways, application compute and the database tier running RDS PostgreSQL and ElastiCache Redis.

The data layer solves cache stampede: Redis atomic SET NX locks mean a single thread queries PostgreSQL when a key expires while concurrent requests wait and re-poll instead of all hitting the database at once, and the write path invalidates keys explicitly so stale data is never served. A Jenkins pipeline runs the init, plan and apply lifecycle with static analysis and injected credentials.

Use case: the moment traffic spikes — a popular key expiring under load — is exactly when a naive cache falls over and the database gets hammered by duplicate queries; this is the pattern that keeps that from happening.
github.com/flexer-dee/Telco_cloud_pipeline
